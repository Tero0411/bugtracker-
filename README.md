# BugTracker

A PHP-based web application focused on managing customer-reported issues through a simple CRUD workflow.

## 🚀 Overview

This project was developed as a practical exercise in web application development and database management.

The application allows users to:

* Register reported issues
* List existing issues
* Update issue information
* Delete issues
* Manage issue priority and status
* Store issue information in a relational database

The project helped me practice the complete flow between a web interface, backend logic, and database operations.

## 🛠️ Technologies

* PHP
* SQL
* MySQL
* HTML
* CSS
* Prepared Statements
* CRUD

## 🗄️ Database Operations

The application uses a relational database to store reported incidents.

Database operations include:

* `INSERT` — Register new issues
* `SELECT` — Retrieve and list issues
* `UPDATE` — Modify existing issues
* `DELETE` — Remove issues

Prepared statements are used for database operations to improve the security and reliability of SQL queries.

## 🔄 CRUD Functionality

The project implements the four fundamental CRUD operations:

**Create**
Register new customer-reported issues with information such as title, description, priority, status, and date.

**Read**
Retrieve and display registered issues from the database.

**Update**
Modify information associated with an existing issue.

**Delete**
Remove an issue from the database.
